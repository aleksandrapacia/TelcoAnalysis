# TelcoAnalysis
*DT model predicting customer churn for a telecommunications provider*
- Database management: SQLite for structured data storage and extraction
- Data engineering: SQL-based feature engineering (using CASE WHEN and WHERE clauses)
- Machine learning: decision tree classifier
- Validation strategy: stratified k-fold cross-validation
- Handling imbalance: Applied class_weight='balanced' to address the minority churn class
